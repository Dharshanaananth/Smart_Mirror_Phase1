# 🪞 Smart Mirror – Phase 1

A Smart Mirror built using **Raspberry Pi**, **Linux**, and **MagicMirror²** to display real-time information and provide interactive media access.

## ✨ Features
- Real-time Date & Time  
- Calendar Integration  
- Weather Updates  
- YouTube Integration  
- Google Quick Access  
- Custom Interactive UI  

## 🛠 Tech Stack
- Raspberry Pi  
- Linux  
- MagicMirror²  
- JavaScript  
- HTML / CSS  

## 🚀 Run

```bash
npm install
npm start
```
